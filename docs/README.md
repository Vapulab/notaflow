# NotaFlow Docs

Every NotaFlow doc lives under this folder. The rules are in the [Documentation Standard](ENGINEERING/CONVENTIONS/DOCUMENTATION_STANDARD.md).

| Category | Where | Use when |
| --- | --- | --- |
| Architecture | [ENGINEERING/ARCHITECTURE/](ENGINEERING/ARCHITECTURE/OVERVIEW.md) | you need the shape of the system and its boundaries |
| Conventions | [ENGINEERING/CONVENTIONS/](ENGINEERING/CONVENTIONS/DOCUMENTATION_STANDARD.md) | you write code or docs, or you handle a secret |
| RFCs | `ENGINEERING/RFCS/YYYY/MM/` | you propose or look up a design decision |
| Plans | `ENGINEERING/PLANS/YYYY/MM/` | you implement an approved RFC, task by task |
| Post-mortems | `ENGINEERING/POST_MORTEMS/YYYY/MM/` | you write up an incident |
| Tutorials | `TUTORIALS/` | you need step-by-step instructions, such as a deploy |
| Marketing | [MARKETING/](MARKETING/CAMPAIGN_LINKS.md) | you share a link to NotaFlow in a post, a bio, or a group |
| Templates | [TEMPLATES/](TEMPLATES/RFC.md) | you start a new RFC, plan, or tutorial |

Dated docs go in the folder of the month they were written.
