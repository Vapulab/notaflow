# NotaFlow marketing

Campaign material for NotaFlow. The brand (logo, icons, colors, fonts) lives in the Vapulab project, in `X:\Projetos\vapulab\brand\`. This folder holds only the campaign pieces.

## instagram/

Launch carousel, 1080×1350 (4:5), made on 2026-10-12. The copy is in Portuguese, for the Brazilian audience.

| File | What it is |
|---|---|
| `notaflow-1.png` to `notaflow-5.png` | The 5 slides, in post order |
| `notaflow-perfil.png` | Profile picture for the account |
| `texto.md` | Post caption, with the hashtags |
| `slides.html` | Source of the slides. Open it in Chrome and take a screenshot of each slide to make them again |
| `avatar.html` | Source of the profile picture |
| `SpaceGrotesk.woff2` | Font for both HTML files. Keep it in the same folder |
